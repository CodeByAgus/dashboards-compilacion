# Dashboard de Análisis de Facturación de Ventas

Este dashboard presenta un **análisis general de la facturación de ventas**, permitiendo visualizar ingresos, productos, marcas, categorías, evolución temporal y distribución geográfica de las ventas.

---
### 📊 KPIs Principales

El dashboard incluye los siguientes indicadores:

- **Facturación total:** $6.997.602  
- **Producto más vendido:** Lente Leica Vario-APO  
- **Categoría más vendida:** Sistema de sonido  


### 📈 Visualizaciones Principales

#### 1. Facturación por Marca
Gráfico de barras que muestra el total facturado por cada marca, destacando las de mayor aporte al ingreso total (por ejemplo: Microsoft, Sonos, Sony, Philips).

#### 2. Total de Facturación por Continente
Mapa geográfico que permite analizar la **distribución de las ventas a nivel global**, identificando regiones con mayor volumen de facturación.

#### 3. Evolución de Facturación y Ventas en el Tiempo
Gráfico combinado: 
- Barras: total de facturación
- Línea: total de unidades vendidas  
La visualización está segmentada por **año y mes**, lo que permite detectar

#### 4. Tabla de Facturación por Año
Tabla resumen con:
- Total facturado por año
- Porcentaje de contribución de cada año al total.
