# Dashboard de Resumen Financiero

![Resumen Financiero](./Resumen%20financiero.png)

Este dashboard presenta un **resumen financiero de ventas** en dólares (USD), permitiendo visualizar ingresos totales, productos vendidos, márgenes, descuentos, evolución temporal y distribución geográfica y por equipo de ventas.

---

### 📊 KPIs Principales

El dashboard incluye los siguientes indicadores clave:

- **Total Ventas:** $1,85 millones
- **Productos Vendidos:** 35 mil unidades
- **Promedio Descuento:** 14,82%
- **Margen de Utilidad:** 13,50%

---

### 🔍 Filtros Disponibles

- **Año:** 2015, 2016, 2017
- **Categoría:** Muebles, Oficina, Tecnología

---

### 📈 Visualizaciones Principales

#### 1. Total Ventas por Región

Gráfico de barras horizontales que muestra el total vendido por cada región geográfica:

| Región  | Ventas       |
|---------|-------------|
| West    | $587 mil    |
| East    | $560 mil    |
| Central | $410 mil    |
| South   | $295 mil    |

#### 2. Total Ventas y Suma de Costo por Equipo de Venta

Gráfico de barras agrupadas que compara el **total de ventas** vs. el **total de costos** por cada equipo de ventas:

| Equipo   | Total Ventas  |
|----------|--------------|
| Organic  | $1.145.762   |
| Delta    | $207.481     |
| Charlie  | $185.005     |
| Bravo    | $175.675     |
| Alfa     | $137.842     |

#### 3. Total Ventas por Valor de Cliente

Gráfico de barras que segmenta las ventas según el valor del cliente:

| Segmento    | Ventas       |
|-------------|-------------|
| Valor Bajo  | $1.686.538  |
| Valor Alto  | $141.547    |
| Valor Medio | $23.680     |

#### 4. Total Ventas por Mes

Gráfico de área/línea que muestra la **evolución mensual de las ventas** a lo largo del año (de enero a diciembre), permitiendo identificar tendencias estacionales y picos de actividad comercial.
